# Agent Skills Directory
## Skills loaded by skills_tool.py

Skills are discovered from:
- `/root/.config/opencode/skills/*/SKILL.md`
- `/root/.agents/skills/*/SKILL.md`

Each skill has a SKILL.md file that defines:
- Name and description
- Trigger patterns
- Tool requirements
- Instructions for the AI agent

## Available Skills
- hack - Hacking commands
- recon - Reconnaissance
- web-attack - Web application attacks
- brute - Brute force attacks
- exploit - Exploitation tools
- report - Report generation
- master - Auto-routing skill
- chat - Normal conversation
- install - Tool installer
- scheduled-tasks - Task scheduling
- build-skill - Skill creation
