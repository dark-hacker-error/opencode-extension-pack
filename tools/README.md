# Tools Directory
## Hacking Tools Collection

This directory contains 21+ hacking tools cloned from GitHub.

> **Note**: Due to GitHub API size limits, these tools are NOT included in the npm package.
> They are available in the GitHub repository for manual cloning.

## Installation
```bash
# Clone just the tools directory
git clone --filter=blob:none --sparse https://github.com/dark-hacker-error/opencode-extension-pack.git
cd opencode-extension-pack
git sparse-checkout set tools
```
