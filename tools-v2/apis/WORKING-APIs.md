# APIs Directory
## OpenSource APIs

### Instagram
1. `https://api.instagram.com/` - Instagram Graph API

### Snapchat
1. `https://api.snap.com/` - Snap Kit API

### Telegram
1. `https://api.telegram.org/` - Telegram Bot API

### YouTube
1. `https://www.googleapis.com/youtube/v3/` - YouTube Data API

### IP
1. `http://ip-api.com/json/{ip}` - IP Geolocation API
2. `https://ipinfo.io/{ip}/json` - IP Info API

### Email
1. `https://emailrep.io/{email}` - Email Reputation API
2. `https://hunter.io/` - Email Finder API

### Phone
1. `https://numverify.com/` - Phone Verification API
2. `https://www.twilio.com/` - Phone API

### GitHub
1. `https://api.github.com/users/{username}` - GitHub User API
2. `https://github.com/` - GitHub Web
